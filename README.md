# Sedap — Food Delivery Dashboard

A food delivery dashboard built with Next.js and Tailwind CSS — orders, menus, customers, analytics, and delivery tracking in one admin view.

## What it does

- **Orders** — track and manage food delivery orders
- **Foods** — manage the menu / food items
- **Customers** — customer list and details
- **Analytics** — charts and insights into sales and orders
- **Calendar & messages** — scheduling and customer messages in the dashboard
- **Wallet** — wallet / payments view
- **Map view** — delivery locations with Leaflet maps
- **Drag-and-drop** — reorderable lists with dnd-kit

## Tech stack

- Next.js 16, React 19, TypeScript
- Tailwind CSS 4
- Recharts (charts), Leaflet + React Leaflet (maps), dnd-kit (drag-and-drop)
- Groq SDK, Lucide icons
